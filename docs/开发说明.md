# gpt-luna-pet · 开发说明

## 1. 技术结构

- Electron 39 / Chromium，Windows x64。
- 主进程创建全屏透明 BrowserWindow，窗口本身透明且默认鼠标穿透。
- `preload.js` 通过 `contextBridge` 暴露最少接口：
  - `setInteractive(Boolean)`：根据指针是否落在桌宠、气泡或设置面板上切换鼠标穿透。
  - `loadThoughts()`：从程序目录读取外置 `thoughts.json`。
  - `quit()`：退出桌宠。
- 渲染层不使用 Node.js，保持 `contextIsolation: true`、`nodeIntegration: false`。
- 托盘由主进程维护，可显示/隐藏与退出。

## 2. 文件职责

| 文件 | 职责 |
| --- | --- |
| `main.js` | 窗口、托盘、单实例、外置思考文本 IPC |
| `preload.js` | 主进程能力白名单 |
| `core.js` | 设置校验、B/C 抽取、随机目的地、路径运动、停驻与碰撞 |
| `app.js` | 形态状态机、气泡、Q 弹、扇翅逐帧、睡眠 Z、缩放、设置 |
| `styles.css` | 透明界面、动作动画、设置面板、气泡和粒子表现 |
| `thoughts.json` | B/C 可编辑文本，数组每项一行 |

## 3. 形态与状态

### B 形态

- `b-idle`：原地呼吸发呆，不参与寻路。
- `b-wings`：八张画，每张保持 3 帧，以 24fps 组成 24 帧循环；运行时通过 `sprite.src` 更新。
- `b-scratch`：±0.9°对称小幅摇晃，2 秒一个周期。
- `b-sleep`：原地睡觉；每 0.38–0.8 秒随机向四周发射 36–54px、5px 紫色粗描边的 Z，位移距离 100–300px，前 70% 行程保持高不透明度后渐隐；单击时立即额外发射 3 个 Z，不弹气泡、不触发变身。
- 睡觉时右上角显示闹钟按钮。点击后玩具锤从右上方砸下，锤子与按钮消失，同时用“碰！”大字和亮色冲击作为遮挡，切换回 `b-idle` 站立发呆。
- B 形态仍可移动，但发呆与睡觉固定原地；非睡眠状态单击会显示或推进 B 思考气泡。
- 设置页 B 形态说明为：“发呆、飞起来、工作（也许？）、寝了”。

### C 形态

- 使用 `assets/sprites/c-native.png`（猊下手工修复版，去除多余白边后的透明图）。
- 静态立绘叠加 1.16 倍显示补偿，避免宽翼在画面中过小。
- 独立 Q 弹设置：
  - `squash`：上下压缩到 85%，横向到 118%。
  - `uniform`：等比缩小到 72%。
  - `off`：关闭弹动。
- C 不触发撞边或点击的通用 Q 弹，不进入到站停留/睡眠。
- 歌词每 4.2 秒切换，点击气泡立即下一句；支持顺序/随机。
- 气泡为粗紫描边的云朵 SVG 背景，文字 20px、800 字重、深紫色；使用透明度+缩放的渐变入场，气泡点饰同步放大。
- 设置页底部显示项目名和运行时版本：`gpt-luna-pet v1.3.0`，版本由主进程 `app.getVersion()` 提供。

## 4. 外置文本

`thoughts.json` 与安装目录的 exe 同级。主进程读取后返回渲染层：

```json
{
  "B": ["啊吧啊吧", "GPT-6-Luna已连接", "额度耗尽", "用户不会发现..."],
  "C": ["哦耶耶", "桃花~谢了有玫瑰"]
}
```

- 数组每行一条；也接受带换行的字符串并按行切分。
- 读取时机：应用启动、在设置中点击“保存并应用”。
- 升级安装使用 `onlyifdoesntexist`，不会覆盖用户已修改的文件。

## 5. 设置与持久化

- `luna-pet-settings-v1`：速度、变向频率、距离、停留概率/时长、整体缩放。
- `luna-pet-appearance-v1`：
  - `cBounceMode`: `squash | uniform | off`
  - `bThoughtMode`: `random | sequential`
  - `cThoughtMode`: `sequential | random`
- 缩放范围 0.5–1.0，默认 0.85；最大 1.0 即原生 320×360 舞台。
- 缩放使用 `.pet-scale` 包层，舞台尺寸、寻路边界、拖拽边界与设置面板定位同步更新。

## 6. 单击变身

- 每次单击独立判定，概率 15%，不要求连点。
- 形态权重 B:C = 50:50。
- 若选择当前形态，则排除当前状态，并随机选择另一个 B 状态；C 只有一种状态时改选另一形态。
- 底部提示固定为“变身！”，不拼接形态名；字号从 11px 提升到 15px。
- B 睡觉时点击提前返回，只追加 Z 粒子，不进入变身判定；其他 B 状态单击会显示/推进气泡。

## 7. 素材流程

### B 扇翅

1. 以 `assets/source/form-b-turnaround-v2.jpg` 与 `assets/source/form-b-front-v2.jpg` 为角色与画风双重参考。
2. 使用 GPT Image 2.5 Sunburst 生成 4×2 八帧原表：`assets/generated/wings-sunburst-v2/wing-sheet.png`。
3. `tools/build_wing_frames_sunburst_v2.py` 按空白间隙切帧，统一脚底中心与 317px 身体高度，输出 `assets/sprites/wings/b-wing-01..08.png`。
4. 运行时按 24 帧/秒推进，每张画持续 3 帧。
5. 内部生成尝试、Flare 版与 Sunburst 第一版均分别归档在 `assets/rejected/`。

### C 立绘

1. 原图存档 `assets/source/form-c-manual.jpg`。
2. 本地去除白底、填补透明孔洞、裁除多余留白，底部基线固定在 390px。
3. 当前输出 256×350 内容，放在 400×400 透明画布。

### 音效

`assets/audio/duck-squeak.mp3` 为猊下提供的小黄鸭原音（约 0.46 秒），点击时以 65% 音量原速播放；原始文件另存于 `assets/source/duck-squeak-source.mp3`。

## 8. 构建与测试

核心测试：

```bat
node tests\core.test.js
```

Electron 交互测试需要 Playwright：

```bat
set NODE_PATH=D:\path\to\playwright\node_modules
node tests\browser.test.js
```

打包运行目录时，将运行文件与素材打入 `resources\app.asar`，并把 `thoughts.json` 放在 exe 同级目录。安装包使用：

```bat
"D:\Inno Setup 6\ISCC.exe" installer\LUNA.iss
```

安装程序默认安装到 `%LOCALAPPDATA%\Programs\LUNA桌宠`，无管理员权限要求。

## 9. 已知限制

- 仅提供 Windows x64 版本。
- A 形态素材保留但不开放。
- 鼠标穿透依赖窗口内指针位置轮询；拖动或悬停时路径暂停。
- 安装器 UI 使用 Inno Setup 英文默认语言，程序名称与路径为中文。
- 开发机器上的旧 NSIS 尝试已由 Inno Setup 取代，不作为正式构建链。
